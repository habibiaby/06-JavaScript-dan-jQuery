1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya!

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. JavaScript dapat digunakan untuk merespons tindakan pengguna, memvalidasi input form, mengubah isi halaman, serta mengatur tampilan elemen HTML tanpa harus memuat ulang halaman.

2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!

jQuery adalah library JavaScript yang mempermudah penulisan kode JavaScript, terutama untuk memanipulasi elemen HTML, menangani event atau kejadian, mengubah CSS, dan membuat efek animasi. Dengan jQuery, kode untuk melakukan berbagai interaksi pada halaman web dapat ditulis dengan lebih sederhana.

3. Jelaskan perbedaan JavaScript dan jQuery!

JavaScript merupakan bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript untuk mempermudah pekerjaan pengembangan web.

Perbedaannya terletak pada cara penulisan dan penggunaannya. JavaScript dapat digunakan secara langsung tanpa library tambahan, sedangkan jQuery memerlukan library jQuery agar fitur-fiturnya dapat digunakan. Contohnya, untuk mengubah warna kotak, JavaScript dapat menggunakan document.getElementById() dan properti style, sedangkan jQuery dapat menggunakan selector $() dan method .css().
